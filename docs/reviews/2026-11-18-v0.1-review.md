## Dismissed candidates (checked, declined, with the evidence)

| Candidate | Evidence that cleared it |
|---|---|
| `recall_at_k` with `k` larger than the list, one query, all-zero qrels, ties, `n=1`/`n=2` bootstrap | Probe: `recall 0.5, precision 0.01, ndcg 0.380, mrr 0.5` for a 1-item list at k=100; `bootstrap_ci([0.5]) == (0.5, 0.5)`; all-zero qrels gives 0 everywhere with a zero-width CI and exit 0; `_quantile` on 1 value hits `upper == lower`. All as METRIC-DEFINITIONS/REPORT-SCHEMA state. |
| Non-inferiority rule vs GATE.md | `passed = round(lo, 6) > -max_drop` is exactly "lower bound rounded to 6 places, strictly above"; `X` must be finite and `> 0` (`ValueError`, exit 1); `--level` outside (0,1) and `--resamples < 1` are `ValueError`, exit 1. Matches the table in GATE.md. |
| Negative or float grades | TREC qrels: `grade < 0` is a `LoaderError`; `1.5` is "must be an integer". JSONL: `-1` rejected. Python API: a negative grade is simply not relevant (documented: grade > 0 is relevant); a float grade `0.5` is relevant to rageval and not to ranx at default `rel_lvl`, which METRIC-DEFINITIONS.md already records. |
| `int("1_0")` accepted as grade 10 in TREC qrels | Python's `int()` accepts underscores. Not a plausible file content; a stricter parser would reject real files for nothing, the same trade-off the loaders already make for the unused TREC fields. Listed, not fixed. |
| Empty run file: all queries score 0, exit 0, no warning | Documented behaviour ("a query the run never answers scores 0"); `run.n_queries_in_run: 0` is in the report. A warning would change report content for a case the user sees as all-zero rows anyway. Listed, not fixed. |
| Windows line endings | `str.strip()` removes `\r`; JSONL lines parse after strip. Fine. |
| Huge files | Loaders stream line by line; `read_run` holds the run in memory, which is the data the user asked to score. |
| Duplicate qids / `(qid, docid)` | Qrels: repeated judgment is a `LoaderError`; non-adjacent lines for one qid merge via `setdefault`. Run: repeats kept and counted (`duplicate_ids`), scored once (METRIC-DEFINITIONS). JSONL repeated `query_id` is an error. |
| Path traversal / symlinks in `--out`, `--summary` | The path is the caller's own choice on their own machine; `write_text` follows symlinks like any CLI. In the Action every input reaches the script through `env:`, so no `${{ }}` injection into `run:`. |
| API key in logs, reports, exceptions, the pack | Key read from the env var at call time only; `JudgeError` for 401/403 names the variable, not the value (locked by `test_openai_compatible_judge_reads_key_from_env_only_and_never_echoes_it`); `scores.json` `detail` is the model's reply text; the pack and key files hold item text and conditions only. Error bodies are truncated server text (a hostile server could echo its own request headers; out of scope). |
| Timeouts | `urlopen(..., timeout=60)` covers connect and read; a connect timeout surfaces as `URLError` ("cannot reach ..."), a read timeout as `TimeoutError`; both are `JudgeError`s with a fix. |
| `pull_request_target`, unpinned actions, `${{ }}` in `run:` | None present; every third-party action is `@<40-hex> # vX`; `tests/test_release.py` locks the pins and that only `testpypi`/`pypi` get `id-token: write`; the PyPI job needs `workflow_dispatch` + `confirm == 'publish'` + a `v*` tag. `actionlint` 1.7.12: clean. `zizmor` 1.32.0 (`--persona auditor`): 2 low (`self-repository`, below), 0 medium, 0 high. |
| zizmor `self-repository`: `uses: ./` in gate-selftest.yml | GitHub's `$/` syntax is real (July 2026) and recommended for `$/path/to/dir`; the form for a root-level `action.yml` is not documented and gate-selftest is a required check, so it was not changed blind. The checkout step precedes `uses: ./` with `persist-credentials: false` and no later step clones anything. Listed for a follow-up once `$/` for the root is verified on a non-required workflow. |
| `scripts/fetch_scifact.py` | `verify(sha256)` runs before `extract`; extraction reads three fixed member names into fixed relative paths (no zip-slip); https only; 120 s timeout; no `subprocess`, no `shell=True` anywhere in `scripts/` or `rageval/`. |
| Wheel contents, `py.typed`, LICENSE, classifiers, `twine check` | Wheel: 11 package files + `py.typed` + `licenses/LICENSE`, no tests or caches. `twine check --strict`: PASSED for both files. Classifiers: `3 - Alpha`, 3.11-3.14, `Typing :: Typed`, all true. |
| Docs numbers | SciFact BM25 `ndcg@10 0.6588`, `recall@100 0.8886`, `mrr@10 0.6288`, truncate diff `-0.0633 [-0.0920, -0.0393]`: reproduced live (transcript A). Toy numbers: reproduced byte-for-byte. `MANIFEST.json` sha256s: locked by `tests/test_scifact_fixtures.py`. |
| Public site claim | <https://amitsinghom.github.io/index.html> says "retrieval-grounded assistants with retrieval evaluation". It is backed by this repository: `rageval run / compare / gate` over TREC and JSONL inputs, metrics cross-checked against ranx to 1.1e-16, a live SciFact BM25 dogfood (nDCG@10 0.6588, 300 queries) and a CI regression gate with a GitHub Action.
